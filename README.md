## Featured project

### [Tiger Games](https://princeton.games) — Co-Founder & Software Developer

A Princeton-focused gaming platform, publicly branded as **Princeton Games**, built collaboratively with Angelo Fernando, Ben Morales, and Latif Tabanli.

My contributions span gameplay, backend development, and interactive UI:

- **TigerLine:** implemented the historical timeline game, including event placement, scoring, saved progress, and tests.
- **Daily leaderboards:** added database models, API routes, and server-side scoring and validation for TigerLine, Imposter Course, and TigerTints.
- **Interactive tiger showcase & theme slider:** built an animated Game of the Day reveal and a persistent light/dark control with pointer and keyboard input, pause controls for the showcase, and reduced-motion handling.
- **Tiger Tiles:** built a campus-themed sliding-tile puzzle with merge logic, combo scoring, saved-state validation, and unit tests.

**Stack:** TypeScript, React, Next.js, PostgreSQL, Prisma, Tailwind CSS, CSS Modules, and Vitest.
